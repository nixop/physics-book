# 0.1. Physics as Model Building

> [!abstract] In brief
> Observation, idealization, model, prediction, and experiment.

## Key ideas

- Observation, idealization, model, prediction, and experiment.
- A model as a useful simplification rather than a literal copy of reality.
- Approximations and domains of applicability.
- The distinction between a law, a model, a hypothesis, and a measured fact.

## Working model

Define the system, name the measurable quantities, and check which assumptions allow these ideas to be applied. Connect the verbal description to a diagram, graph, and dimensional analysis.

> [!warning] Limits of the model
> The result is meaningful only while the assumptions hold. Test a limiting case and compare the scale of the effect with measurement uncertainty.

## Formulas

- [[../Formula Index#Normalized Model Residual|Normalized Model Residual]] — z = (x_obs − x_model) / sqrt(σ_obs² + σ_model²)
