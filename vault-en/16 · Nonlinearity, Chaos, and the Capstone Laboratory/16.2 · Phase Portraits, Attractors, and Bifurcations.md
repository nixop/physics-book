# 16.2. Phase Portraits, Attractors, and Bifurcations

> [!abstract] In brief
> A dynamical-system state is the smallest variable set that, with the evolution law, predicts the next state. Each state is a point in phase space and a solution becomes a trajectory, so stability and transitions can be studied without plotting every coordinate against time.

## Core explanation

A fixed point, limit cycle, or more complicated invariant set is an attractor when neighboring trajectories approach it. Smooth parameter variation can qualitatively change the number or stability of these regimes; that event is a bifurcation.

## Key ideas

- **The state of a dynamical system.** — For n first-order equations, state is normally an n-component vector. An oscillator needs position and velocity together; position alone does not determine its direction of subsequent motion.
- **Fixed points, cycles, and attractors.** — At a fixed point the state-space velocity is zero. A limit cycle is an isolated closed orbit that other trajectories may approach; not every closed curve is an attractor.
- **Changes in behavior as a parameter is varied continuously.** — Before a critical parameter, a system may return to one regime and afterward move toward two new states or an oscillation. Smooth coefficients do not guarantee a smoothly changing long-term qualitative response.
- **Bifurcations.** — A bifurcation is defined by changed topology or stability of invariant regimes, not merely rapid numerical growth. Classification depends on symmetry, dimension, and nonlinear terms.

## Short example

- **Problem:** Analyze equilibria of dx/dt = μx - x³ as parameter μ crosses zero.
- **Answer:** At μ = 0 one stable branch loses stability and two symmetric stable branches appear: a supercritical pitchfork bifurcation.
- **Check:** The new solutions exist only for μ > 0 and continuously approach zero as μ approaches zero from above, as this normal form requires.

> [!warning] Limits of the model
> A phase portrait belongs to a specific autonomous model and variable set. Projection from high dimension can create false crossings; noise blurs an attractor, and a finite parameter sweep may miss hysteresis. A local normal form is valid only near its bifurcation.

> [!danger] Common mistake
> A plot that resembles branching does not prove a bifurcation. One must demonstrate changing stable solutions with the parameter and exclude transients, noise, and insufficient settling time.

## Self-check

1. Why can two trajectories of a smooth autonomous system not cross in full phase space?

> [!tip]- Answer and guide
> At an intersection, one state would have two different future directions.
> Solution uniqueness assigns one velocity vector to each state. An apparent crossing can occur only in projection, with nonsmooth dynamics, or with missing variables.

2. For μ = 0.04, find every equilibrium of μx - x³ and its stability.

> [!tip]- Answer and guide
> Use x* = 0, ±√μ and the sign of μ - 3x*².
> The points are 0 and ±0.20. Zero is unstable and both ±0.20 points are stable.
