# Физические константы

| Символ | Величина | Значение | Примечание |
|---|---|---:|---|
| $c$ | Скорость света в вакууме | 299792458 м/с | Точное определяющее значение СИ. |
| $G$ | Гравитационная постоянная | 6.6743e-11 м³/(кг·с²) | CODATA 2022; стандартная неопределённость равна 0.00015e−11 м³/(кг·с²). |
| $h$ | Постоянная Планка | 6.62607015e-34 Дж·с | Точное определяющее значение СИ. |
| $\hbar$ | Приведённая постоянная Планка | 1.054571817e-34 Дж·с | Округлённая десятичная запись точного соотношения ħ = h/(2π). |
| $e$ | Элементарный заряд | 1.602176634e-19 Кл | Точное определяющее значение СИ; заряд электрона равен −e. |
| $k_{\mathrm B}$ | Постоянная Больцмана | 1.380649e-23 Дж/К | Точное определяющее значение СИ. |
| $N_{\mathrm A}$ | Постоянная Авогадро | 6.02214076e+23 моль⁻¹ | Точное определяющее значение СИ. |
| $R$ | Универсальная газовая постоянная | 8.31446261815324 Дж/(моль·К) | Точное произведение N_A k_B. |
| $\varepsilon_0$ | Электрическая постоянная | 8.8541878188e-12 Ф/м | CODATA 2022; после переопределения СИ является измеряемой производной величиной. |
| $\mu_0$ | Магнитная постоянная | 0.00000125663706127 Н/А² | CODATA 2022; после переопределения СИ не равна точно 4π·10⁻⁷ Н/А². |
| $\alpha$ | Постоянная тонкой структуры | 0.0072973525643 безразмерно | CODATA 2022; характеризует силу электромагнитного взаимодействия. |
| $m_e$ | Масса электрона | 9.1093837139e-31 кг | Рекомендованное значение CODATA 2022. |
| $m_p$ | Масса протона | 1.67262192595e-27 кг | Рекомендованное значение CODATA 2022. |
| $m_n$ | Масса нейтрона | 1.67492750056e-27 кг | Рекомендованное значение CODATA 2022. |
| $m_u$ | Атомная единица массы | 1.66053906892e-27 кг | CODATA 2022; обозначается также u или дальтон (Da). |
| $g_0$ | Стандартное ускорение свободного падения | 9.80665 м/с² | Точное условное значение; локальное ускорение свободного падения зависит от места. |
| $\sigma$ | Постоянная Стефана—Больцмана | 5.670374419e-8 Вт/(м²·К⁴) | Округлённая десятичная запись значения, выводимого из точных c, h и k_B. |
| $\mathrm{eV}$ | Электронвольт в джоулях | 1.602176634e-19 Дж | Точное преобразование: 1 эВ — энергия заряда e при прохождении разности потенциалов 1 В. |
