# 3.3. Второй закон Ньютона

> [!abstract] Коротко
> Равнодействующая внешних сил.

## Главное

- Равнодействующая внешних сил.
- Для материальной системы фиксированного состава сумма внешних сил равна производной её импульса по времени.
- При постоянной массе второй закон принимает вид `ΣF = ma`.
- Векторная запись и уравнения по осям.
- Начальные условия и численное предсказание движения.
